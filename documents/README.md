# Documents

Skills for creating and working with documents: PDFs, reports, proposals and similar files.

## Skills

| Skill | What it does |
|---|---|
| [**PDF Atelier**](pdf-atelier/) | Polished, themed PDFs with 12 color themes and full RTL support (Persian, Arabic, Hebrew). |

## Adding a skill here

1. Create a folder: `documents/<skill-name>/`
2. Add a `SKILL.md` with `name` and `description` in the frontmatter.
3. Add a short `README.md` and link the skill in the table above.
