# Git

Skills for everyday git workflows: commits, branches and history.

## Skills

| Skill | What it does |
|---|---|
| [**Commitsmith**](commitsmith/) | Writes scoped one-line commit messages like `fix(order): correct tax calculation`. |

## Adding a skill here

1. Create a folder: `git/<skill-name>/`
2. Add a `SKILL.md` with `name` and `description` in the frontmatter.
3. Add a short `README.md` and link the skill in the table above.
